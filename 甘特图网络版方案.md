# 甘特图网络版方案

## 1. 需求分析

### 核心需求
1. **局域网访问**：同一局域网下的同事都能访问该甘特图应用
2. **数据同步**：运行该软件的电脑作为服务器，其他同事修改的内容会自动同步到服务器和其他客户端
3. **功能补充**：根据客户可能的需求，补充必要的功能

### 现有系统分析
- 现有系统是一个纯前端的甘特图应用，使用HTML、CSS和JavaScript开发
- 数据存储在本地的localStorage或IndexedDB中
- 不支持多用户协作和数据同步

## 2. 技术方案

### 2.1 技术选型

| 类别 | 技术/工具 | 版本 | 选型理由 |
|------|-----------|------|----------|
| 服务器 | Node.js + Express | v16+ | 轻量级、跨平台、易于部署，适合作为局域网内的小型服务器 |
| 前端 | 现有HTML/CSS/JS | - | 保持现有界面和功能，只需修改数据存储和同步逻辑 |
| 实时通信 | Socket.io | v4+ | 提供实时双向通信，适合数据同步场景 |
| 数据存储 | JSON文件 | - | 简单易用，适合小型应用，不需要复杂的数据库 |
| 部署工具 | PM2 | v5+ | 进程管理，确保服务器稳定运行 |

#### 数据流设计
1. **初始化**：客户端连接服务器，获取最新数据
2. **数据修改**：客户端修改数据后，发送到服务器
3. **数据同步**：服务器接收数据，保存到文件，并广播给所有客户端
4. **数据更新**：客户端接收服务器广播的数据，更新本地界面

## 3. 详细实现

### 3.1 服务器端实现

#### 1. 创建服务器项目

#### 2. 服务器代码 (app.js)
```javascript
const express = require('express');
const http = require('http');
const socketIo = require('socket.io');
const fs = require('fs');
const path = require('path');

const app = express();
const server = http.createServer(app);
const io = socketIo(server);

// 数据文件路径
const dataFilePath = path.join(__dirname, 'data', 'gantt-data.json');

// 确保数据目录存在
if (!fs.existsSync(path.join(__dirname, 'data'))) {
    fs.mkdirSync(path.join(__dirname, 'data'), { recursive: true });
}

// 读取数据
function readData() {
    try {
        if (fs.existsSync(dataFilePath)) {
            const data = fs.readFileSync(dataFilePath, 'utf8');
            return JSON.parse(data);
        }
        return null;
    } catch (error) {
        console.error('读取数据失败:', error);
        return null;
    }
}

// 写入数据
function writeData(data) {
    try {
        fs.writeFileSync(dataFilePath, JSON.stringify(data, null, 2));
        return true;
    } catch (error) {
        console.error('写入数据失败:', error);
        return false;
    }
}

// 静态文件服务
app.use(express.static(path.join(__dirname, '../client')));

// 数据API
app.get('/api/data', (req, res) => {
    const data = readData();
    res.json(data || {});
});

app.post('/api/data', express.json(), (req, res) => {
    const success = writeData(req.body);
    res.json({ success });
});

// Socket.io 连接
io.on('connection', (socket) => {
    console.log('新客户端连接:', socket.id);
    
    // 发送初始数据
    const initialData = readData();
    if (initialData) {
        socket.emit('data', initialData);
    }
    
    // 接收数据更新
    socket.on('update', (data) => {
        console.log('收到数据更新');
        const success = writeData(data);
        if (success) {
            // 广播给所有客户端
            io.emit('data', data);
        }
    });
    
    socket.on('disconnect', () => {
        console.log('客户端断开连接:', socket.id);
    });
});

// 启动服务器
const PORT = process.env.PORT || 3000;
server.listen(PORT, () => {
    console.log(`服务器运行在 http://localhost:${PORT}`);
    console.log(`局域网访问地址: http://${getLocalIP()}:${PORT}`);
});

// 获取本地IP地址
function getLocalIP() {
    const os = require('os');
    const interfaces = os.networkInterfaces();
    for (const devName in interfaces) {
        const iface = interfaces[devName];
        for (let i = 0; i < iface.length; i++) {
            const alias = iface[i];
            if (alias.family === 'IPv4' && alias.address !== '127.0.0.1' && !alias.internal) {
                return alias.address;
            }
        }
    }
    return '127.0.0.1';
}
```
