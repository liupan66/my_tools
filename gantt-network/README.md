# 甘特图网络版

## 项目介绍

甘特图网络版是一个基于Node.js和Socket.io的实时协作甘特图应用，支持同一局域网内的多用户访问和数据同步。

## 功能特性

- **实时数据同步**：多用户同时编辑时，数据会实时同步到所有客户端
- **局域网访问**：同一局域网内的同事可以通过服务器IP地址访问
- **数据持久化**：数据存储在服务器的JSON文件中，重启服务器后数据不丢失
- **完整的甘特图功能**：支持任务管理、项目管理、执行人管理、节假日设置等
- **响应式设计**：适配不同屏幕尺寸

## 技术栈

- **前端**：HTML、CSS、JavaScript
- **后端**：Node.js、Express
- **实时通信**：Socket.io
- **数据存储**：JSON文件

## 快速开始

### 1. 安装依赖

```bash
cd server
npm install
```

### 2. 启动服务器

```bash
npm start
```

服务器启动后，会显示访问地址：
```
服务器运行在 http://localhost:3000
局域网访问地址: http://[服务器IP]:3000
```

### 3. 访问应用

- 服务器本地访问：http://localhost:3000
- 局域网内其他电脑访问：http://[服务器IP]:3000

## 注意事项

1. **局域网访问**：确保所有设备在同一局域网内，并且服务器防火墙允许3000端口的访问
2. **数据备份**：定期备份 `server/data/gantt-data.json` 文件，以防数据丢失
3. **性能优化**：对于大型项目，可能需要优化服务器性能
4. **浏览器兼容性**：建议使用现代浏览器访问，如Chrome、Firefox、Edge等

## 功能使用

### 任务管理
- **添加任务**：点击"添加任务"按钮，填写任务信息
- **编辑任务**：点击任务右侧的"编辑"按钮
- **删除任务**：点击任务右侧的"删除"按钮
- **拖拽调整**：拖拽任务条可以调整任务的开始和结束时间

### 项目管理
- **添加项目**：在"设置"标签页中，点击"添加项目"按钮
- **删除项目**：在"设置"标签页中，点击项目右侧的"删除"按钮
- **项目颜色**：可以为每个项目设置不同的颜色

### 执行人管理
- **添加执行人**：在"设置"标签页中，点击"添加执行人"按钮
- **删除执行人**：在"设置"标签页中，点击执行人右侧的"删除"按钮
- **执行人排序**：拖拽执行人可以调整顺序

### 节假日设置
- **添加节假日**：在"设置"标签页中，点击"添加节假日"按钮
- **删除节假日**：在"设置"标签页中，点击节假日右侧的"删除"按钮
- **周末设置**：可以设置周六、周日为工作日

### 数据导入导出
- **导出Excel**：点击"导出Excel"按钮
- **导入Excel**：点击"导入Excel"按钮，选择Excel文件
- **导出SVG**：点击"导出SVG"按钮
- **导出JSON**：点击"导出JSON"按钮

## 常见问题

### 1. 局域网内其他电脑无法访问
- 检查服务器防火墙是否允许3000端口的访问
- 确保所有设备在同一局域网内
- 尝试使用服务器的IP地址访问

### 2. 数据同步不及时
- 检查网络连接是否稳定
- 刷新页面后重试

### 3. 服务器重启后数据丢失
- 检查 `server/data/gantt-data.json` 文件是否存在
- 确保服务器有写入权限
